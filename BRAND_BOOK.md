# The Chase — Unlock the City · Brand Book

> A location-based game where players run through their real city, chase down
> crystals, open portals and outwit the horned Serpent and the Agent.
> The brand is **night-city electric**: chrome and deep navy, lit by a cyan
> beam on one side and an ultraviolet beam on the other.

Every colour in this book was sampled from the key art in [`base-images/`](base-images/)
and is defined once in [`tokens/colors.json`](tokens/colors.json)
(CSS: [`tokens/colors.css`](tokens/colors.css)). If this book and the tokens ever
disagree, **the tokens win**.

### 2.7 Proportion

On any screen or poster aim for roughly:

```
████████████████████████████████████████ 60%  midnight / void / night-navy
██████████████████                       25%  shield-blue / electric-blue / signal-blue
████████                                 10%  chrome / silver
██                                        5%  chase-cyan + ultraviolet glows
```

Glow colours are light sources. Small, bright and few: if more than ~5% of the
frame glows, nothing does.

## 3. Logo

All files are in [`assets/logo/`](assets/logo/) and [`assets/app/`](assets/app/).
The SVG emblem is a clean vector redraw of the key-art logo
(`base-images/PHOTO-2026-02-18-06-48-21*.jpg`).

| File | Use |
|---|---|
| `emblem.svg` | Primary mark with glow, on dark backgrounds |
| `emblem-flat.svg` | Same without blur filters: small sizes, email, print |
| `emblem-mono.svg` | One colour via `currentColor` (inline it and set `color`) |
| `wordmark.svg` / `wordmark-ink.svg` | Text only, for dark / light backgrounds |
| `lockup-horizontal.svg` / `lockup-horizontal-ink.svg` | Emblem + wordmark side by side, dark / light |
| `lockup-stacked.svg` | Emblem over wordmark, matches the key art |
| `app/app-icon.svg` | 1024 × 1024 store icon on `night-sky` |
| `app/favicon.svg` | Simplified emblem for 16–48 px |

### Anatomy

1. **Crown-star shield** in chrome, filled with `shield-blue`.
2. **Mask**: inner star ring, a central blade and two pillars ("II").
3. **Side shards**, one each side.
4. **V-beam**: cyan on the left, violet on the right, meeting at a bright point.
5. **Skyline** glowing inside the V: the city being unlocked.

### Rules

- **Clear space**: the height of the side shard (≈ 1/16 of emblem width) on all sides.
- **Minimum size**: `emblem.svg` 48 px, `favicon.svg` 16 px, wordmark 80 px wide.
- **Backgrounds**: the full-colour logo lives on `void`, `midnight` or `night-sky`.
  On light or photographic backgrounds use the `-ink` lockups or `emblem-mono` in `midnight`.
- **Don't**: recolour the beams, swap cyan/violet sides, add a drop shadow,
  outline the chrome, rotate or skew, set the wordmark in another font, or put the
  full-colour logo on mid-tone blues where the shield disappears.

## 4. Typography

| Role | Typeface | Notes |
|---|---|---|
| Logo / display lettering | **Chase Display** — the angular monoline caps generated by `wordmark.py` | Faceted 20% chamfers echo the emblem. All caps, wide tracking. Use for logos, titles on key art, achievement banners. Output is SVG paths, no font file needed |
| Headings (app & web) | **Space Grotesk** 600–700 | Matches the marketing site |
| Body / UI | **DM Sans** 400–600 | Matches the marketing site |
| Numbers / labels | Geist Mono | Timers, coordinates, scores |

Display lettering is always uppercase. Headings in sentence case; never all-caps body text.

## 5. Iconography

### UI icons — [`assets/icons/ui/`](assets/icons/ui/)

- 24 × 24 grid, 2 px live-area padding, **2 px stroke**, square caps, **miter joins**.
- No fills, colour only through `currentColor`: they inherit text colour.
- Angular, faceted shapes (diamonds, hexagons, chamfers) instead of circles where it reads.
  The diamond is the recurring motif (pin, scan, coin, search).

Set: `home map compass location-pin player-position scan camera inventory profile team
leaderboard trophy quest portal district gem coin energy shield serpent lock unlock timer
sparkle notification chat settings share search info check close back plus`

### Game icons — [`assets/icons/game/`](assets/icons/game/)

- 64 × 64, full colour, palette tokens only, gradients allowed.
- Every gradient/clip `id` is prefixed with the file name (`gem-…`) so icons can be
  inlined together on one page.
- Top-left light source; a thin `ice` or `serpent-shade` outline separates the
  object from any background.

Set: `gem coin portal beacon serpent agent-badge energy key xp-star lock-district district quest-marker trophy`

## 6. Imagery and illustration

- **Style**: painterly, semi-realistic digital illustration; clean cel-shaded characters
  on white for sprites, full scenes with deep perspective for key art.
- **Light**: magic is always cool (cyan → violet). Warm light only comes from the real city
  (sunlight, sandstone, terracotta) and from gold.
- **Motifs**: floating crystals over a glowing ring, swirling portals in the sky,
  lightning arcs, four-point sparkles, real landmarks seen from above.
- **Characters**: keep proportions and colours consistent with the sheets in
  `base-images/` (Serpent: 2 golden horns swept back, beaked snout, purple eyes, cyan rune lines;
  Agent: slicked dark hair, scar over the right brow, chrome pauldrons with blue light strips).

## 7. Voice

Short, energetic, second person. Verbs first. Playful about the villains, never mean to the player.

- ✅ "Grab the crystal before the Serpent does."
- ✅ "District unlocked. The cathedral is yours."
- ❌ "Users can collect items by navigating to locations."

## 8. Making new assets

Use the **`chase-brand-assets`** skill in
[`.agents/skills/chase-brand-assets/`](.agents/skills/chase-brand-assets/SKILL.md).
It works with any agent that reads `AGENTS.md` or Agent Skills (Claude Code, Codex,
Cursor, Gemini CLI, Copilot…) and includes:

- `wordmark.py`: brand lettering for any text
- `build_logo_suite.py`: rebuild every logo variant after editing `emblem.svg`
- `check_svg.py`: validate an asset against the rules in this book
- `gallery.py`: preview every asset on dark and light

### Relation to the marketing site

The website (`../the-chase_web-page`) currently uses a different "night-city glass" palette
(violet / rose / cyan / lime in OKLCH). To align it with this book, map
`--brand-ink → midnight`, `--brand-violet → ultraviolet` / `violet-glow`,
`--brand-cyan → chase-cyan`, and use `electric-blue` as `--primary`.
`rose` and `lime` have no counterpart in the key art.
